# Changelog

All notable changes to this project are documented here.

## [1.0.0] - 2026-10-01

### Added

- CPU-friendly molecular graph regression notebook.
- Delaney/ESOL dataset download through `requests`.
- RDKit SMILES-to-graph conversion.
- PyTorch Geometric GCN model.
- MAE and RMSE evaluation.
- Flask web application for SMILES prediction.
- GitHub and LinkedIn profile links in the web app.
- Contribution guide and repository documentation.
