# Contributing to GNN for Drug Discovery

Thanks for your interest in improving this project.

## Before You Start

- Keep the repository lightweight and CPU-friendly.
- Keep the main implementation in the notebook unless a change genuinely belongs in the Flask app.
- Do not add a `src/` directory or separate preprocessing/module scripts.
- Avoid committing downloaded datasets or generated model binaries.

## Reporting Bugs

Open an issue with:

- Operating system
- Python version
- Package versions
- Steps to reproduce
- Full traceback or screenshots when useful

## Suggesting Features

Explain:

1. The problem the feature solves.
2. The proposed approach.
3. Why it fits the project's lightweight scope.

## Pull Requests

1. Fork the repository.
2. Create a focused branch.
3. Make the smallest useful change.
4. Run the notebook or the relevant application checks.
5. Update `CHANGELOG.md` when the change is user-visible.
6. Open a pull request with a clear description.

## Code Style

Prefer readable Python, descriptive variable names, small functions, and comments only where they clarify the reasoning.
