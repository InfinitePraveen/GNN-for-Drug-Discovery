# GNN for Drug Discovery

Predict molecular properties from chemical structures represented as graphs.

This project uses a lightweight Graph Neural Network (GNN) with **PyTorch Geometric** and **RDKit** to predict aqueous solubility from SMILES strings. The model is trained on the open **Delaney/ESOL** dataset and can be demonstrated through a small Flask web application.

## Why this project?

A molecule can be represented as a graph:

- **Nodes** → atoms
- **Edges** → chemical bonds
- **Node features** → atomic number, degree, charge, hybridization, aromaticity and hydrogen count
- **Target** → measured log solubility in mol/L

The notebook trains a two-layer GCN and evaluates it with MAE and RMSE. The Flask app accepts a SMILES string and returns a predicted solubility value.

## Dataset

The project uses the Delaney ESOL dataset. It contains 1,128 compounds with SMILES strings and measured aqueous solubility values. The notebook downloads the CSV when needed instead of committing the dataset to Git.

Dataset source used by the notebook:
`https://deepchemdata.s3-us-west-1.amazonaws.com/datasets/delaney-processed.csv`

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
```

Linux/macOS:

```bash
source .venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

If PyTorch Geometric installation depends on your local PyTorch build, follow the current PyG installation instructions and then install the remaining requirements.

## Run the Notebook

```bash
jupyter notebook
```

Open:

```text
notebooks/GNN_Drug_Discovery.ipynb
```

Run all cells. The notebook will:

1. Download the ESOL CSV with `requests`.
2. Load and inspect the data.
3. Convert SMILES molecules into PyTorch Geometric graphs.
4. Create train/validation/test splits.
5. Train a small CPU-friendly GCN.
6. Report MAE and RMSE.
7. Save the trained model to `models/gnn_esol.pt`.
8. Save model metadata to `models/model_config.json`.

The default training configuration is intentionally small so it can run on a CPU without a GPU.

## Run the Web App

After running the notebook and generating `models/gnn_esol.pt`:

```bash
python app.py
```

Open:

```text
http://127.0.0.1:5000
```

Enter a SMILES string such as:

```text
CCO
```

The app converts the molecule into a graph using the same feature representation and sends it through the trained GCN.

### Important

The web app expects the trained model file generated by the notebook. This is deliberate: the ZIP stays small and the model is reproducibly generated from the public dataset instead of shipping a large binary artifact.

## Interview Talking Points

You can explain the project in this sequence:

1. **Problem:** molecular solubility is a useful molecular property for early-stage drug discovery.
2. **Representation:** SMILES is parsed by RDKit and converted into a graph.
3. **Graph learning:** GCN layers aggregate information from neighboring atoms.
4. **Readout:** global mean pooling creates one vector for the complete molecule.
5. **Regression:** a small MLP predicts log solubility.
6. **Evaluation:** MAE and RMSE quantify prediction error on unseen molecules.
7. **Deployment:** Flask exposes the trained model through a simple browser interface.

## Limitations

This is an educational/interview project, not a validated drug-discovery system. ESOL measures aqueous solubility, not drug efficacy, toxicity, binding affinity, or clinical outcomes. Predictions should not be interpreted as experimental or medical advice.
